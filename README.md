# solo-spot-map

Solo Spot Mapは、一人で入りやすいカフェ・喫煙所・漫画喫茶・深夜スポットを検索できるプロトタイプです。

## Concept

- 一人利用歓迎、喫煙可、電源あり、深夜営業などの条件で探せる
- 「2名様から」「シングルチャージあり」など、一人利用で困る条件を見える化する
- 待ち時間、バス到着後、仕事前後の短時間利用に向く場所を提案する
- 将来的に口コミ、地図、投稿、閉店確認、広告導線へ拡張する
